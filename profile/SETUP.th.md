# เปิดใช้โปรไฟล์ตามรูปแบบตัวอย่าง

README นี้จัดเป็นหัวข้อแนะนำตัวตรงกลาง ปุ่มติดต่อ About Me, Skills, Projects และแถวไอคอน ตามรูปแบบที่คุณส่งมา โดยใช้ชื่อและผลงานของ BunnyBubui

## เปิดใช้จริงบน GitHub

1. สร้าง repository ชื่อ **BunnyBubui** ภายใต้บัญชี **BunnyBubui** และตั้งเป็น **Public**
2. นำ README.md และ assets/ จาก profile-kit.zip ไปไว้ที่ root ของ repository
3. Commit ลง default branch แล้วเปิด https://github.com/BunnyBubui

การเชื่อมต่อ GitHub ปัจจุบันอนุญาตแก้ไฟล์ใน repo เดิม แต่ปฏิเสธ createRepository จึงต้องสร้าง repo โปรไฟล์หนึ่งครั้งผ่านหน้าเว็บ GitHub
