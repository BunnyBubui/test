# ติดตั้ง GitHub Profile README

ชุดนี้เตรียมสำหรับบัญชี **BunnyBubui** โดยใช้ข้อมูลชื่อและผลงานจาก GitHub ไม่มีการเพิ่มอีเมล เบอร์โทร การศึกษา หรือประสบการณ์ที่ยังไม่ได้ยืนยัน

## เปิดใช้

1. สร้าง repository ชื่อ **BunnyBubui** ภายใต้บัญชี **BunnyBubui** และตั้งเป็น **Public**
2. นำ `README.md` และโฟลเดอร์ `assets/` จาก profile-kit.zip ไปไว้ที่ root ของ repository
3. Commit ลง default branch แล้วเปิด https://github.com/BunnyBubui

ไฟล์ภาพและลิงก์ใช้โครงสร้างเดียวกับชุด preview จึงย้ายไป repo โปรไฟล์ได้โดยไม่ต้องแก้ path
